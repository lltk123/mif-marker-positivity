# 2026-10-29 更新

本次发布 TabM CD8 基线、三种子消融结果，以及已有校准实验的统一排序。

- **TabM A/B/C：** 固定官方版本，实现训练、推理和评估入口；完成每组 3 个随机种子及相同特征的 HGB 对照。保留配置、特征清单、汇总 CSV、PNG/SVG 图表和开发案例。
- **校准实验汇总：** 按同一外部有标签集合整理 E1–E4 与 GMM，分别报告固定 0.5 和训练 OOF 门限。主榜为 E2 > E4 > E1 > E3 > GMM，完整数值见 [CALIBRATED_RANKINGS.csv](../analyses/cd8_calibrated_results_summary_20261029/CALIBRATED_RANKINGS.csv)。
- **复现与可读性：** 增加只依赖 Python 标准库的汇总重建入口；TabM 发布源码统一排版，AST 等价核验见 [代码整理记录](publication/tabm_readability_20261029.csv)。
- **发布范围：** 只提交代码、配置、报告、汇总表和派生图件；全量逐细胞结果、原始数据、权重、环境和访问凭据保留原处。Pan-M 继续封存。

Nimbus 预训练与微调首轮实验已完成，当前没有正在运行的 Nimbus 训练。其后续任务适配尚未开展；本次没有修改 Nimbus 或重跑既有模型。
