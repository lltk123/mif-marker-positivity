# 2026-10-31：百分位校准与 TabM／Nimbus 重训练

本次发布已完成的 PhenoBIC CD8 校准、重训练及新旧性能比较。保留全部旧实验，不重跑原 GMM 或 E1–E4；Pan-M 继续封存。

- **共同校准：** 每实例先取像素 P10/P90，再在完整 WSI／单个 TMA 组织芯内取外层 P1/P99，获得共享 L/U。对归一化像素重新提取特征，保留所有实例。共 48 个单位、1,817,783 个细胞，全部校准有效。
- **TabM：** A/B/C 为 8/27/90 项输入，各完成种子 0/1/2；匹配 HGB 对照保留相同特征与划分。正式发布训练、预测、评估入口、特征清单、配置、模型元数据和汇总结果。
- **Nimbus：** 固定作者 V1 版本，分别完成新尺度直接推理与从 V1 单独微调。完整预测覆盖每个原始实例，保存切块接缝及标签对应核查。
- **报告与图表：** 提供中文 MD、总体／逐芯／错误分层 CSV、训练资源统计，以及中英文 PNG 和文字可编辑 SVG。固定 0.5 与内部验证所选门限分别列出。
- **可追溯性：** 保留冻结协议、依赖版本、原运行哈希、独立数值审计和发布源码的 AST／哈希对照。本次整理只更新文档与发布副本排版，没有修改模型或数值结果。
