# 数据范围与适用性补充

- 本轮只消费 PhenoBIC CD8 的既有特征表、显式标签映射和开发集原图案例。Pan-M 图像、标签、分布及预测未读取，也没有为跨数据集重叠检查解封它。当前结果不支持宣称 Pan-M 独立性或跨数据集泛化。
- TabM 从随机初始化训练，无外部预训练权重，因此不存在继承预训练见过 Pan-M 的问题。本轮不改变 Nimbus 的既有来源独立性限制。
- 原官方切分保持不变。可用患者 ID 缺失，采用 WSI 分组；外部组织芯按芯汇报，但不能当作独立患者。显式键不重复不等同于证明所有原始像素绝无重叠；本轮没有新增全数据原图去重扫描。
- 训练和评价复用已经验证过的完整逐细胞数值特征。没有在本轮重新提取全部原图，也不把特征表可读当成逐文件重新下载审计。
- C 的接触侧、高局部参照和方向不均匀性分层是数值代理；开发图例只做工程核对，不是新病理复核标签。弱阳性代理依据训练正类的原始亮度分位数，跨图像强度尺度会影响其含义。
- 研究代码、汇总表和图件可进入审阅包；完整逐细胞预测、32成员概率、原始图像裁剪、权重及完整曲线保留在服务器。模型路径和权重 SHA256 见 results/report_model_artifacts.csv。
