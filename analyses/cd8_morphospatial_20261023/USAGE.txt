Main outputs

PhenoBIC_CD8_model_predictions.parquet: labels and old GMM/new-model results joined AFTER extraction by the same explicit key. Unannotated cells remain present.
FEATURE_DICTIONARY.csv/json: formula, unit, conditions, missingness reasons, model-input role.
RUN_CONFIG.json: feature parameters, source commit, versions and source-code hash.
TRAINING_PROTOCOL.json: fixed supervised evaluation protocol.
results/: metrics, missingness, QC, completion audits.
models/: fitted sklearn model bundles with ordered feature lists and training image IDs.
scripts/: reusable extraction API, CLI, PhenoBIC batch adapter, controlled tests and classifier training.

For large data use bounding-box ROIs with halo >= ceil(max(r_outer, neighbor_distance)) + 2 pixels. Retain all neighbor instance IDs in each ROI. Supply global origin=(y,x), valid support and force_truncated when a source image cuts a cell. A binary ROI must not be interpreted as a new cell segmentation. Interpretation
The paper describes buffered nuclear convex hulls, so mask_type=expanded_nucleus. Edges approximate cell boundaries and are not proven membranes. inner does not mean nucleus. Original nuclear masks, verified pixel spacing and tissue masks are absent. Local reference can contain cytoplasmic/neighbor/unsegmented-cell or tissue-exterior signal. reference_tissue_unknown flags this limitation. No tissue mask is inferred from CD8.
Pixel-space geometry and original-intensity features are retained. No per-cell normalization. No independent physical-scale results without supplied pixel spacing. Crop-only display contrast is not used in calculations.
Edge width=max(1,0.2*maximum internal EDT); reference radii 2 and 5 px; neighbor distance 2 px; epsilon=1e-8 in original intensity units. Small (<5 pixels), truncated/disconnected or invalid-signal regions have documented NaN/QC. Reference needs >=20 pixels, sectors >=2 pixels, sector summaries >=6 of 12 sectors. High-signal threshold median+3*1.4826*MAD is an engineering descriptor, not a positive-cell rule; MAD=0 makes coverage undefined. No-signal flags describe unstable localization metrics, not cell class.

Morphometry
HistomicsTK 1.4.0 requires Python >=3.9, incompatible with this Python 3.8 environment. scikit-image fallback was used. Its 19 outputs were compared with the actual released HistomicsTK function on disk, ellipse and rectangle masks; all agreed numerically. This does not establish universal equivalence. Degenerate/invalid shapes intentionally output NaN, unlike some HistomicsTK denominator fallbacks. Orientation is radians from the row axis according to actual regionprops behavior (not the horizontal-axis wording in the HistomicsTK docstring). Perimeter is digital; circularity may exceed 1. FractalDimension/WeightedHuMoments are excluded.

Models and evaluation
HistGradientBoostingClassifier, fixed 150 iterations, learning_rate=.06, 15 leaves, min_samples_leaf=80, l2=2, no early stopping, random_state=0. Native missing-value handling, no QC-based row removal. intensity_8 uses 8 whole-mask intensity statistics; morphospatial_90 uses the complete 90-feature set. Metadata, coordinates, IDs, QC flags, labels and GMM outputs are excluded as model inputs. Supervised fitting uses only 101,057 annotated cells in original 3 training WSIs. Probability >0.5 defines positive. No validation/test-based tuning. Three leave-one-training-WSI-out folds are descriptive OOF checks. Final training resubstitution scores are not generalization estimates.
Old GMM is reused exactly and has per-image unsupervised calibration. Supervised classifiers use manual labels; comparisons do not have equal supervision. Internal/external subsets are PhenoBIC development benchmarks, not the sealed Pan-M Gold test set. Cells within an image are correlated; per-unit and macro metrics are supplied instead of cell-bootstrap confidence intervals. Patient independence beyond original dataset documentation is not assumed. Pixel intensity scales vary (TMA3 is uint8; WSI/TMA1/TMA2 float32), which can affect transfer of a fixed classifier.
